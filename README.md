# Axel's Home Assistant Add-ons

Axel's Home Assistant add-on repository.

## Add to Home Assistant

**Settings > Add-ons > Add-on Store**, then open the top-right menu and choose **Repositories**. Enter:

```
https://github.com/axelburks/ha-addons
```

Once added, all add-ons below appear in the store; click one, then **Install**.

## Add-ons

| Add-on | Description |
|--------|-------------|
| [Mihomo Proxy](./mihomo) | Mihomo (Clash.Meta) TUN transparent proxy. |

> Each add-on's options, usage and caveats live in the `README.md` inside its directory.
